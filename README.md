# Hemma

Gemensam app för Adrian & Kemal: matschema (frukost, lunch, middag), inköpslista och delad matkassa.

- Ren HTML/CSS/JS i `index.html`, publiceras med GitHub Pages.
- Data sparas i Firebase Firestore under `hem/<nyckel>/...`.
- Nyckeln skickas med i länken efter `#` och sparas sedan i telefonen. Den finns inte i koden.
